# Especificaciones

Una carpeta por feature grande: `NNN-slug/` con `requirements.md`,
`design.md` y `tasks.md`.

El flujo es `/spec-new` → `/spec-design` → `/spec-tasks` → `/spec-build`, con
aprobación del usuario entre cada paso.

**Esto es opcional.** Para una feature normal, la skill `kiro-feature` basta y
no gasta esta ceremonia. Usa specs cuando la feature es lo bastante grande como
para que valga la pena pensarla entera antes de escribir código.
