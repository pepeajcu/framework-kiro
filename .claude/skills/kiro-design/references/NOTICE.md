# Origin of these files

## Vendored from taste-skill (MIT)

`minimalist.md`, `soft.md`, `brutalist.md`, `redesign.md` and `brandkit.md` are
verbatim copies of `skills/minimalist-skill`, `skills/soft-skill`,
`skills/brutalist-skill`, `skills/redesign-skill` and `skills/brandkit` from
[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill), MIT licensed
(see `LICENSE-taste-skill`).

They are written for React/Next/Framer projects in places. Where they say
"React", "Framer Motion" or name a CDN font, `SKILL.md` one level up wins: this
project is Jinja + HTMX + Tailwind, with nothing loaded from a CDN. Two things
in them do not work here and are worth knowing before following them:

- **`Cabinet Grotesk`, `Satoshi`, `General Sans`** are Fontshare fonts. They are
  not on Fontsource, so `make font` cannot install them. See `type-pairings.md`
  for families that are.
- **`https://picsum.photos/...` placeholders** are blocked by the CSP
  (`img-src 'self' data:`, ADR-0010). Use a local SVG or photo under
  `app/static/img/`.

`redesign.md` is the audit `/kiro-redesign` runs. `brandkit.md` describes how to
brief a brand-identity image; Kiro does not generate images, so use it as the
checklist for what a logo and a visual system should be, and for judging the
logo a person brings.

**Pinned to a commit.** These five files are byte-identical to
`Leonxlnx/taste-skill@9da1763c950baed17a69158a5f4c76f8f85bf49b` (2026-10-12,
checked with `git hash-object` against the blob SHAs the GitHub API reports).
Upstream shipped **taste-skill v2 on 2026-10-13**: a rewrite of `skills/taste-skill`
with no dials, a Node 22 and Chrome toolchain, and bans on glass, hairlines,
`01/02` numbering and monospace that several Kiro styles rely on on purpose. Kiro
follows the dial-based method (v1, still in the repo as `skills/taste-skill-v1`);
v2 is not adopted, its "tells" are only advice. Always refresh from the pinned
commit, never from `main`, and bump the pin on purpose.

To refresh them, or to move the pin:

    REF=9da1763c950baed17a69158a5f4c76f8f85bf49b
    for s in minimalist brutalist soft redesign; do
      gh api "repos/Leonxlnx/taste-skill/contents/skills/$s-skill/SKILL.md?ref=$REF" --jq .content | base64 -d > references/$s.md
    done
    gh api "repos/Leonxlnx/taste-skill/contents/skills/brandkit/SKILL.md?ref=$REF" --jq .content | base64 -d > references/brandkit.md

(`redesign-skill` is saved as `redesign.md`, `minimalist-skill` as `minimalist.md`,
and so on: the `-skill` suffix is dropped.) A changed file will also change the
copy of its toml block in `tests/test_design_docs.py`; run the suite.

## Vendored from uupm (MIT)

`../uupm/` is a copy of the search scripts and data of
[nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
at **v2.15.0** (commit `a38d04c3d5c298c851dbe5e6ee1965ee3de42cb5`), MIT licensed (see
`../uupm/LICENSE`). Only a closed list of files is taken (the search engine, the
CSVs for styles, palettes, typography, landing patterns, UX guidelines, charts and
motion, and the `html-tailwind` stack). Left out on purpose: the icon sets, the
2 MB Google Fonts catalogue, every other stack, React-only data and upstream's tests.

- Its `SKILL.md` is saved as `GUIDE.md` so that it is not a second design skill.
- Every file is pinned by SHA-256 in `../uupm/vendor.lock.json`; a test fails if one
  is edited by hand. The files are byte-identical to upstream.
- `../uupm-kiro/` is *ours*: uupm's data translated to what Kiro can do, generated by
  `scripts/vendor_uupm.py`.

To move to another version: change `VERSION` and `COMMIT` in `scripts/vendor_uupm.py`,
run `make vendor-uupm` (needs the network), read the diff, and run the suite: the
overlay tests will say what no longer holds.

## Written for Kiro

`archetypes.md`, `type-pairings.md`, `constitution.md`, `estandar-shadcn.md`, `ios.md`,
`expresivo.md`, `institucional.md`,
`panel-de-datos.md`, `editorial.md`, `neo-brutalista.md`, `retro-y2k.md`,
`organico.md` and `oscuro-tecnologico.md` are original to this project. They
follow the *method* of taste-skill (named styles with dials, anti-slop rules)
but are adapted to Jinja, HTMX, Basecoat and `design.toml`.
